Datheon Python Programming Internship

This repository contains Python projects completed as part of my Python Programming Internship tasks.

Projects

1. Hangman Game ("hangman.py")

A command-line word guessing game where players guess letters to reveal a hidden word. The game tracks incorrect guesses and displays the result.

Concepts used: Variables, lists, loops, conditional statements, user input, and the random module.

2. Rule-Based Chatbot ("chatbot.py")

A simple interactive chatbot that responds to greetings and basic questions using predefined rules.

Concepts used: Strings, loops, conditional statements, lists, and user input.

How to Run

Run either Python file in a Python environment:

- "hangman.py"
- "datheon.py"
